name: calendar-generate
description: Append or write Markdown content for the selected day.
---

This is 生成内容 for a day work plan. The caret is the selected date.
Selection fields: `date` (YYYY-MM-DD), `text` (existing Markdown, may be empty).

Produce Markdown to add for that day as `replacement`. The editor appends it
under any existing content for the same date.

Do not invent timed events, titles, or all-day flags — only the day's content.
Mention extra ideas only in `answer`.
Use [the shared contract](../common/contracts.md).
When you need live web facts, include [external tools](../common/external-tools.md).
