# Screen Backgrounds

These are bundled static photographs from Unsplash. No external image requests are made at runtime.

- `orbit.webp`: NASA, orbital view of Earth. Original image: https://images.unsplash.com/photo-1446776811953-b23d57bd21aa
- `stars.webp`: Micha Lehmann, starry alpine night. Source: https://unsplash.com/photos/the-night-sky-with-stars-above-a-mountain-range-IXM3iSrj3QE
- `lake.webp`: Mattia Poli, mountain lake. Source: https://unsplash.com/photos/a-mountain-lake-surrounded-by-snow-covered-mountains-XPVVtqCQWzY

License: https://unsplash.com/license

The image CDN was requested with WebP output, bounded width and compressed quality. Images are loaded only when opening the screen overlay or its settings.
